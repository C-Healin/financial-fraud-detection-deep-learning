# Data Card

## Included data

`data/sample/fraud_sample.csv` is fully synthetic and generated by this repository. It contains no real customer, card, or merchant information.

## Feature groups

- Numerical: distance, age, amount, city population
- Categorical: gender, job, category, city, state, ZIP, merchant, and transaction time parts
- Graph identifiers: card and merchant
- Target: `is_fraud`

## Intended use

The sample data supports demonstrations, CI tests, portfolio screenshots, and code review. It is not suitable for estimating production fraud rates or business impact.

## Leakage controls

Preprocessors are fitted on the training split only. Graph adjacency is built only from training edges. Validation data selects the decision threshold; test data is reserved for final metrics.
